# Demo walkthroughs

Presenter tools live in the dashed **Prototype** bar at the top: **Viewing as** (switch user and surface), **Walkthroughs** (guided steps), **Scope**, the demo clock (default 10:40 AM, drives due / overdue) and **Reset demo**. On a large screen the Care Staff experience is shown inside an iPad frame (toggle in the bar).

Each guided walkthrough opens a small card bottom-left with **Back / Go to step / Next / exit**. Every step signs in the right demo user, opens the right screen and outlines the element to talk about. The prototype stays fully clickable while it is open.

Before a meeting: **Reset demo**, and check **Scope** is "Full roadmap scope".

Demo credentials: any seeded email or employee ID, password `demo`, MFA code `246810`. PIN = last four digits of the employee ID (Sarah 2014, James 2031, Grace 2002).

## A · Administrative setup (about 6 min)

1. **Sign in with MFA.** Web Admin sign-in → "Use Dana Whitfield" → Continue → "Fill code" → Verify. Point out: individual account, verification step, a Care Staff account is refused here.
2. **Clients.** Name, DOB / age, location, care area, status; search and care-area filter.
3. **Create a client.** New client → *Fill sample client* (Olivia Grant) → Create. Mention required fields and the duplicate check (try creating her again).
4. **Client record.** Emily Carter: demographics, indicators (G-tube indicator comes from the device record), who on staff can see her.
5. **Care schedule.** Care Schedule tab → *Add scheduled care* (e.g. "Nebulizer check", 10:30, every day, Observations) → it will show on the iPad immediately. Toggle active / inactive; open "1 change" for history.
6. **Medications.** Medication, dose, route, times, days. Say explicitly: no drug database, interactions or e-prescribing.
7. **Staff & access.** Invite a staff member (role, title, location, care areas) → invitation code shown. Deactivate / reactivate; history stays attributed (Tom Keller appears in older records).
8. **Audit trail.** Filter by category / user / client: sign-ins, documentation, schedule changes, record prints, access changes.
9. **Switch to Care Staff.** Walkthrough switches to Sarah on the iPad; the new client / item is there.

## B · Care Staff daily documentation (about 8 min)

1. **Client board.** Sarah (LVN) sees only her location and care areas; due / overdue counts and last documentation per client.
2. **Filter by care area.**
3. **Open Emily Carter.** Header: age, DOB, care area, height / weight, indicators.
4. **Today's required care.** Completed (who / when), overdue (Position change), due now (G-tube site care), upcoming. "Not done" records a reason.
5. **Daily flow sheet.** Entries from James (PCA) and Sarah; Timeline / Hourly view.
6. **Document intake.** 120 mL formula via G-tube → saved with time and attribution; I/O card updates.
7. **Medication.** Glycopyrrolate 12:00 → Given (Held / Refused / Omitted need a note) → dose shows Completed.
8. **Assessment.** Accordions; *Mark within normal limits*; COVID-19 Yes / No.
9. **Hand over the iPad.** User menu → *Lock & switch user* → James → PIN 2031. James records a brief change with urine output: it counts in Intake & Output without a second entry.
10. **Shared timeline.** Contributions distinguishable by person; tap an entry → *Record a correction* (original kept).
11. **Review & complete.** Sign as PCA / Licensed Nurse (RN where applicable), parent copy offered / accepted, *Complete flow sheet* → read-only; later entries are addenda.
12. **Records.** Client + date range or *current authorization period* → open → *Print / save as PDF*.

## Questions to ask while demoing

- Is this the daily workflow you need? Who translates physician instructions into scheduled care?
- Which assessment sections and fields are universal vs client-specific? Is COVID-19 still needed?
- What do the PCA / Licensed Nurse / RN signature areas mean, and who must sign?
- Is the PIN hand-over how the shared iPads will be used?
- Is current-authorization-period history needed at launch?
