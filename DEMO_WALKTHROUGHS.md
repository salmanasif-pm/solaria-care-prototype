# Demo walkthroughs

Presenter tools live in the dashed **Prototype** bar at the top: **Viewing as** (switch user and surface), **Walkthroughs** (guided steps), **Scope**, the demo clock (default 10:40 AM, drives due / overdue) and **Reset demo**. On a large screen the Care Staff experience is shown inside an iPad frame (toggle in the bar).

Each guided walkthrough opens a small card bottom-left with **Back / Go to step / Next / exit**. Every step signs in the right demo user, opens the right screen and outlines the element to talk about. The prototype stays fully clickable while it is open.

Before a meeting: **Reset demo**, and check **Scope** is "Full Phase 1 roadmap scope" (future enhancements off).

Labels used below: **[Core]** leanest Phase 1 · **[Optional]** Phase 1 roadmap scope that can be removed · **[Future]** not in the Phase 1 estimate.

Demo credentials: any seeded email or employee ID, password `demo`, MFA code `246810` (Sarah SC-2014, James SC-2031, Grace SC-2002).

## A · Administrative setup (about 6 min) - all [Optional] Web Admin scope

1. **Sign in with MFA.** Web Admin sign-in → "Use Dana Whitfield" → Continue → "Fill code" → Verify. Point out: individual account, verification step, a Care Staff account is refused here.
2. **Clients.** Name, DOB / age, location, care area, status; search and care-area filter.
3. **Create a client.** New client → *Fill sample client* (Olivia Grant) → Create. Mention required fields and the duplicate check (try creating her again).
4. **Client record.** Emily Carter: demographics, indicators (G-tube indicator comes from the device record), who on staff can see her.
5. **Care schedule.** Care Schedule tab → *Add scheduled care* (e.g. "Nebulizer check", 10:30, every day, Observations) → it will show on the iPad immediately. Toggle active / inactive; open "1 change" for history.
6. **Medications.** Medication, dose, route, times, days. Say explicitly: no drug database, interactions or e-prescribing.
7. **Device baseline.** Emily → Devices: G-tube type / size maintained here only; the iPad shows it read-only.
8. **Staff & access.** Invite a staff member (role, title, location, care areas) → invitation code shown. Deactivate / reactivate; history stays attributed (Tom Keller appears in older records).
9. **Audit trail.** Filter by category / user / client: sign-ins, documentation, schedule changes, record prints, access changes.
10. **Switch to Care Staff.** Walkthrough switches to Sarah on the iPad; the new client / item is there.

## Questions to ask while demoing

- Is this the daily workflow you need? Who translates physician instructions into scheduled care?
- Which assessment sections and fields are universal vs client-specific? Is COVID-19 still needed?
- What do the PCA / Licensed Nurse / RN signature areas mean, and who must sign?
- Is log out / sign in acceptable for hand-over on shared iPads, or is a faster switch worth a future phase?
- Is current-authorization-period history needed at launch?
